BloomStreak · 项目介绍

把坚持变成一座会发光的花园。

BloomStreak 是一个移动端优先、花园隐喻的习惯打卡 Web 应用。先在上方 Demo 里创建习惯并打卡，再查看下方项目能力与开源信息。

花园成长反馈每天完成一个小习惯，就像浇灌一株植物，让坚持变得可见。
清晰 Streak当前连续天数、最长连续天数和累计打卡次数一目了然。
开源可扩展完整 Next.js 应用、LocalStorage 与 Supabase 数据层、测试和文档都在 GitHub 仓库中。
阅读项目 README 访问 GitHub 仓库
BloomStreak 是一个开源习惯花园 MVP。数据边界和完整应用说明请查看 README 与 安全说明。
